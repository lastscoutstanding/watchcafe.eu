# watchcafe.eu - accuracy standards for "How it compares" in the Rate Meter
# One standard per line:  Label | Name | min | max | aliases
#   Label    short name, used in the chart band and the summary line
#   Name     longer name in the table
#   min/max  allowed average daily rate in s/day, e.g. -4 and +6
#   aliases  other names a watch's spec may use, separated by ;  (optional)
# A watch's spec (Collection, Details) can be a label, name or alias from this
# list, or a range of its own: "-2/+4", "±2" or "±15 s/month".
# The table follows this order; a watch's own spec always comes first, and is
# the band shown in the chart until another standard is clicked.
# Matching ignores case, accents, spaces and punctuation.
# Lines starting with # are ignored.
